What happens when you talk to ISHA

Every request follows the same six steps, so ISHA stays fast and predictable.

Built with

Hands-free control with your webcam

Switch on gesture mode and ISHA tracks your hand with MediaPipe. A live preview window shows what it sees. Lower your hand or open your palm and the cursor stops.

Security and safety come first

An assistant that controls your computer must be trustworthy. Every ISHA action is sorted into one of three risk levels, and anything not yet classified is treated as needing your approval.

Safe

Runs instantly
  • Open apps and websites
  • Volume, brightness, mute
  • CPU, RAM, battery, Wi-Fi checks
  • Search and read files
  • Play music, use memory

Confirm

Asks you first
  • Write, move or rename files
  • Delete a file
  • Close a running process
  • Save generated code

Critical

Asks loudly
  • Run terminal commands
  • Run code files
  • Delete many files at once
  • Empty Recycle Bin
  • Shut down or restart
  • Protected system processes cannot be closed.
  • Only a fixed list of keyboard shortcuts can be pressed.
  • File actions stay inside your own folders: Desktop, Documents, Downloads, Pictures, Music and Videos.
  • Deleted files go to the Recycle Bin, not gone forever.
  • Generated code is checked against a list of dangerous patterns before it runs.
  • The AI model runs on your PC, so your chats stay with you.

Common questions

Does ISHA work without internet?

The AI brain runs on your PC, so yes. The neural voice and YouTube music search need internet. Without it, ISHA switches to an offline voice.

Can ISHA change or delete my files on its own?

No. Writing, moving and deleting files always needs your approval, and deleted files go to the Recycle Bin.

Which languages does it understand?

Hindi, Hinglish and English. You can switch between them in the same conversation.

Do I need a microphone or webcam?

No. You can type in the chat box. The microphone (voice) and webcam (gestures) are optional extras.

Which computer do I need?

Windows has the fullest support, and Linux and macOS also work. Pick a model size by RAM: 8 GB for 3B, 16 GB for 7B, 32 GB for 14B.

Get ISHA for your PC

Install ISHA and start talking to your computer. It sets up its own Python environment on first run.
